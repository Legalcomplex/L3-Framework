# S3 World Citation Benchmark

**Can a frontier model confirm that a real legal document exists — from memory, with no
retrieval?**

Four frontier models from two providers were asked 2,716 true/false questions each about
real official legal documents from 227 jurisdictions. The best of them confirmed **7.4%**
of the genuine citations. All four rejected fabricated ones at 97.6–99.5%.

This repository contains the generator, the item bank, the runner, every raw per-item
result, and the report for each sweep, so the numbers can be checked rather than taken on
trust.

## The finding

| Model | Provider | Run date | Judged | Aggregate | TRUE items | FALSE items | Said "true" | Cost |
|---|---|---|---|---|---|---|---|---|
| Claude Opus 4.8 | Anthropic | 2026-07-19 | 2,691 | 52.6% | **7.4%** | 97.6% | 4.9% | $5.23 |
| Claude Haiku 4.5 | Anthropic | 2026-07-19 | 2,712 | 52.3% | 6.6% | 98.0% | 4.3% | $0.90 |
| Grok 4.1 Fast (non-reasoning) | xAI | 2026-06-20 | 2,716 | 51.9% | 5.8% | 98.1% | 3.9% | $0.09 |
| Claude Sonnet 5 | Anthropic | 2026-07-19 | 2,716 | 50.5% | 1.5% | 99.5% | 1.0% | $2.26 |

Chance is 50% by construction — the item bank is half true, half false.

**Read the two accuracy columns together.** A 97.6% rejection rate on fabricated citations
looks like discrimination, but a model that answered "false" to everything would score
~100% there, ~0% on the true half, and ~50% aggregate. That is close to what these models
do: Opus 4.8 said "true" on 4.9% of all judged items, Sonnet 5 on 1.0%. The behaviour is
not fake-detection. It is skepticism without knowledge — doubting everything, including
documents that exist.

Aggregate accuracy sits 0.5–2.6 points above chance across the four. On this task, the
frontier is at the coin flip.

## What is being measured

Each item is a single bibliographic claim about one real document — its title, publishing
source, date, or identifier. No legal doctrine, no interpretation, no reasoning about
holdings. Half the items quote a real document verbatim. The other half are the same
documents with exactly one controlled mutation:

| Mutation | What changes | Opus 4.8 caught |
|---|---|---|
| `wrong-source` | attributed to another jurisdiction's publisher | 100.0% (n=718) |
| `id-mutation` | identifier altered to a near-miss | 99.1% (n=232) |
| `date-shift` | publication date moved | 92.5% (n=399) |

Every false item is false *by construction*, and each records both the mutation applied and
the true fact it was derived from. That asymmetry matters for reading the results: the false
half's labels are certain, the true half's labels inherit whatever the source metadata got
right (see [Open items](#open-items)).

Three statement shapes are used — `S1-published-via`, `S2-decision`, `S3-identifier` —
reported separately in each sweep report.

## Method

- **Item bank:** 227 packs × 12 items = 2,716 items per sweep, generated by
  `generate_world_packs.py` from `data/world-law-catalog.json`, deterministic under the
  seed namespace `s3-world-v1`.
- **Condition:** one API call per item, one round, no retrieval, no web access, thinking
  disabled. Model memory only.
- **Grading:** exact match against the first `\b(true|false)\b` token in the response. No
  LLM judge, no partial credit, no rubric.
- **Sampling:** full packs. Every item in the bank, every sweep. No subsetting.

**Temperature was not uniform across the four runs, and the sweep reports say so.** The
xAI run was made at temperature 0. On the three Anthropic runs the parameter was not
accepted by the API and the provider default applied. Any single-sentence summary of this
benchmark that claims "temperature 0" throughout is wrong; the per-run conditions in each
`SWEEP-REPORT-*.md` are authoritative.

The Grok sweep also ran on framework sha `53cba04`, the three Anthropic sweeps on
`7c9132e`. Prompt construction and true/false extraction are unchanged between them, but
strict comparability across that boundary has not been re-established by a re-run.

## Reproducing it

```bash
export ANTHROPIC_API_KEY=...          # or XAI_API_KEY for --provider xai
python run_world_sweep.py --help
```

A full sweep is 2,716 calls and cost $0.09–$5.23 depending on the model, taking 10–22
minutes wall time. `make_sweep_report.py` turns a results directory into the markdown
report; `make_benchmarks_manifest.py` produces `manifest.json`.

To rebuild the item bank from the catalog instead of using the shipped packs:

```bash
python generate_world_packs.py        # deterministic; seed namespace s3-world-v1
```

## Open items

These are stated rather than resolved, because publishing them is cheaper than being
caught with them.

1. **The true-half labels have not been independently audited.** A ~30-item pack-label
   audit is scheduled for 15–31 August 2026. The true items are only as accurate as the
   harvested metadata behind them: if some "true" statements are not in fact true, the
   models were right to refuse them and the 7.4% moves up. The false half needs no such
   audit — those labels are true by construction. **If you find a mis-labelled item, open
   an issue.** That is the single most useful contribution this repository can receive.
2. **Aggregate accuracy inherits that same uncertainty**, since it is computed over both
   halves. A correction to the true half moves the aggregate by roughly half as much.
3. **25 unparsed responses in the Opus run, 4 in the Haiku run.** Accuracy is computed over
   judged items (2,691 and 2,712), not the 2,716 sent. Unparsed responses are neither
   credited nor penalised.
4. **Publishing the item bank exposes it to future training data.** A model trained on this
   repository could score well by recall rather than knowledge. Anyone re-running these
   packs against a model released after August 2026 should treat the result as
   contaminated. The generator is deterministic and included, so a fresh bank under a
   different seed namespace is the way to keep measuring.
5. **Single run per model.** No repeat sweeps, so no variance estimate. Treat small
   differences between models as unresolved.
